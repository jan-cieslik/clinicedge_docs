# Present aggregate test results

**Access:** application administrator or `questionnaires` viewing permission (management includes viewing), using a standard staff account. In **Administration > Questionnaires**, choose the presentation-chart icon beside a **test**. Classroom management or supervisor assignment alone does not grant this access. Surveys do not have this mode.

## Set the teaching scope

1. Choose the published test revision.
2. Optionally select a classroom.
3. Apply a rolling time window in minutes (default 60).
4. Confirm the displayed completed-participant count before discussing results.

Different revisions are never combined. Changing revision clears the classroom filter; an open presentation stays pinned until you change it.

The window uses final **submission time**, not attempt start time. Each participant contributes their latest final submission within scope, even if the test occurs more than once.

## Reveal and discuss

Questions and choices are visible before answers. **Reveal answers** highlights correct choices and shows animated vote bars. Numeric questions reveal the target/tolerance and distribution.

Next/Previous hides the answer again, including when returning to an earlier question. Changing filters also resets reveal. Reduced-motion preferences are respected.

## Explain the denominator

Only completed submissions count; unfinished drafts are not displayed. Multiple-choice percentages use responding participants, so they can sum above 100%. Conditional questions may have fewer respondents than the test's total completed count.

The endpoint returns aggregate counts rather than names or individual answer documents. That does not make every classroom discussion anonymous: avoid revealing a small group's identity through context.

For a public counts-only projection or a shared clinical seminar, use the distinct [projection tools](./projection.md).
