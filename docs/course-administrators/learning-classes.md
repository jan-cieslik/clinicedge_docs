# Create interactive learning classes

**Access:** `classrooms` management permission, or application administrator. Open **Administration > Learning Class Templates**. Questionnaire permission is separate and does not grant learning-class authoring.

## Build a reusable module

1. Create a template and select its required source case.
2. Add and order information text, images/media, practice elements, and questions.
3. Preview the material and check image captions, wording, answers and feedback.
4. Save the template.
5. Select it in a classroom sequence, review the copied contents, then publish the sequence.

Later template edits do not change an already published course snapshot.

## Available elements

The native editor supports information text, captioned raster images, approved audio/video, accordions, flashcards, single/multiple choice, true/false, numeric answers, short reflections, fill-in-the-blanks, and matching pairs.

Text uses Markdown without raw HTML. Upload private images or use approved secure sources. Matching choices are shuffled for learners, so do not make correctness depend on display order.

These are ClinicEdge modules, **not H5P packages**. H5P import/export is not supported.

## Responses and completion

Learners can save and resume their work. Final submission completes the sequence activity and locks submitted responses. Objective elements are scored; reflections are retained for moderators but not scored. There is no pass-score threshold for unlocking the next activity.

Explain this distinction in the activity instructions so students do not confuse formative practice with a pass/fail examination.

## Before publication

Use synthetic learner access to check all element types, mobile media layout, response persistence, final submission, and the next activity. Approve media rights and de-identification; protected delivery cannot make an identifying image safe to publish.
