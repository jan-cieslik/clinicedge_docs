# Create a case when assigned

Some courses use a **creation** classroom rather than an ordinary patient list. Your teacher will explain the authoring objective and expected clinical scenario.

## Start from the classroom

1. Open the assigned creation classroom.
2. Create or continue your owned case template using its offered controls.
3. Develop the scenario, patient context and expected findings as instructed.
4. Test the generated patient and refine the template.
5. Return to the same classroom/template to continue.

Depending on access, your owned templates can also appear under **My templates**. Use the assigned course path so the work remains associated with the right classroom.

## Template versus patient

A template describes how cases are generated. A patient attempt is one generated instance. Editing a template should not be confused with correcting the notes on an already generated patient.

Creating your own case does not grant permission to publish institution-wide clinical content or edit another author's work.

## Work within access limits

ID/PIN students need an authorized creation classroom; generic standalone authoring is not a substitute for it. When a scheduled window ends, retained work may be read-only.

Use fictional data and approved images. Do not import patient documents or upload identifying clinical photographs.

If the creation controls are missing, ask the teacher to check the classroom mode, assignment, and schedule instead of starting an unrelated practice patient.
